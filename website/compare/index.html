How the approach differs

Many API clients keep requests in an account or workspace and sync them through a vendor service. RequestTailor keeps them as files in a folder and leaves sharing to Git, so a request has a history, a diff and a code review like any other file. The app is a view on that folder; the command line and the MCP server read the same files with the same core.

Moving from Postman, Bruno or Insomnia

  • Postman: import a collection (v2.0 or v2.1) with its environment and globals files. Scripts carry over with a pm.* compatibility layer; the report names every API it does not cover.
  • Bruno: a collection in OpenCollection YAML opens as it is and is written back byte for byte.
  • Insomnia: import an export (v4 JSON or YAML, v5 YAML).
  • OpenAPI or Swagger: the wizard builds a collection from a spec and keeps the spec for checks before and after sending.

Start at getting started or the import reference. Secret values are never imported into files; you enter them once.
