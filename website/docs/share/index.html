Share and copy requests

Send a request to a colleague or into another tool without an account and without uploading anything.

Share link

A link looks like https://app.requesttailor.com/#rt=1.<data>. The data is the request, compressed and encoded, and it sits after the #: a browser never sends that part to a server. Creating a link makes no network request and there is no upload. A typical request gives a link of about 1000 characters (at most 2000 at the 95th percentile); the limit is 8000, and a QR code works up to 2000.

The same request is also copied as plain rt:<data> text, which RequestTailor recognises when you paste it. Pasting a link, the fragment or an rt: text opens the request as an unsaved draft. Nothing runs and nothing is sent until you send it.

What is never in a link

  • Secret values. The link has the definition with unresolved {{variables}} and variable names; auth keeps its type and {{secret:<name>}}.
  • Values of ordinary variables, unless you switch on Include variable values.
  • Anything the secret scanner takes for a credential: if it cannot be replaced, no link is made.

Copy as cURL, fetch or Python

Copy a request as a curl command, a JavaScript fetch call or Python code. Variables stay variables of the target: $TOKEN in the shell, process.env.TOKEN in JavaScript, os.environ["TOKEN"] in Python, so no secret value lands in your clipboard. With the OData plugin switched on, a request can also be copied as ABAP for ABAP Platform or ABAP Cloud (see SAP and OData).

Create a request from a snippet

Paste a cURL command into the New… dialog and RequestTailor builds the request without any model or network call. rt import also reads cURL, HAR, .http files, Postman, Insomnia and OpenAPI; see importing.
