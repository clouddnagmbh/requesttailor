AI assistants

Optional helpers that use your own key or a model on your computer. RequestTailor has no AI service of its own, and nothing goes through our servers.

Providers

ProviderNotes
AnthropicYour API key; direct from the browser too.
OpenAIYour API key.
Azure OpenAIThe v1 API of your resource; the model is your deployment name.
Google GeminiYour API key; direct from the browser too.
MistralYour API key.
OpenAI-compatibleOllama, LM Studio, vLLM or a company gateway, by base URL (for example http://localhost:11434/v1, no key needed).

You can set up several profiles and pick one for quick tasks and one for harder ones. The key is kept in the OS keychain (desktop) or encrypted in the browser (web app). In the web app, providers other than Anthropic and Gemini are called through the companion rt agent, because their servers do not allow calls from a browser.

What it does

  • Create a request from a description or a snippet. A cURL command is converted locally, without a model.
  • Explain a response or an error.
  • Suggest assertions or tests from a response, and names for requests.
  • Draft documentation as <request>.md next to the request.

Answers are proposals. They show as a diff or preview first and are applied as an unsaved change you can undo; the assistant never saves or sends anything itself.

What leaves your computer

  • Nothing, until you turn it on and ask. It is off by default.
  • Before the first call per profile and device, What will be sent shows the exact content. You can keep it on for every call.
  • Secret values are replaced by *** before anything leaves the app, and so are credentials typed into headers, URLs or bodies, also in tool inputs and outputs.
  • A collection can switch AI off with extensions.requesttailor.ai.enabled: false in opencollection.yml, and each device can opt out. The interface then says AI is off for this collection.
  • No telemetry. Calls go from your device to the provider you chose.
