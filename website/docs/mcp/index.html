MCP server

Not in this release. The MCP server is planned for a later version. This page says what is decided so far.

The Model Context Protocol lets AI agents call tools. RequestTailor's MCP server will be part of the rt command line and use the same core as the apps, so an agent sends requests exactly as you would, from the same collection files.

The project's rules for agents are fixed already:

  • Agents never see secret values. They work with variable names; values are added by the core when sending and masked in what the agent gets back.
  • Requests that write to a production environment need your approval.
  • Every agent action is written to a local audit log on your machine.

Until then, agents can already use rt send, whose JSON report is made to be read by programs. See Command line: rt.
