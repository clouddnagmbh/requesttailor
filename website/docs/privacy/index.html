Privacy

RequestTailor sends what you send, to where you send it. Nothing else.

The app and the command line

  • No account. There is no sign-in, no license key and no registration.
  • No telemetry. No usage statistics, no crash reports, no analytics are collected or sent.
  • No connection to our servers. The app does not check for updates and does not load content from the internet.
  • Connections you cause. The requests you send; Git remotes you pull from or push to; the OAuth 2.0 provider and browser sign-in of an auth configuration; the command lines of secret managers you configure; the AI provider you set up, only when you ask the assistant (secret values masked, see AI assistants); and hosts a plugin is permitted to reach, which you see before installing it.

Shared links keep the request in the part after #, which a browser never sends to a server; creating one makes no network request (share and copy). The webhook inbox of rt inbox keeps requests in memory only and listens on 127.0.0.1.

rt keeps no history. It shares the keychain entries and the plugin folder with the desktop app, and keeps cookies only in a file you name with --cookie-jar.

The companion rt agent listens on your own machine only (127.0.0.1), logs the method and host of each request it sends, never paths, headers or bodies, and keeps its pairing tokens in memory.

This website

This website is a set of static pages. It sets no cookies, runs no scripts (the only script elements are JSON-LD data blocks for search engines, which are not executed), uses no analytics and loads no fonts, images or scripts from other servers. The hosting provider (GitHub Pages) keeps its own technical server logs; see GitHub's privacy statement for what those contain.
