Privacy

RequestTailor sends what you send, to where you send it. Nothing else.

The app and the command line

  • No account. There is no sign-in, no license key and no registration.
  • No telemetry. No usage statistics, no crash reports, no analytics are collected or sent.
  • No connection to our servers. The app does not check for updates and does not load content from the internet.
  • Connections you cause. The requests you send; Git remotes you pull from or push to; the OAuth 2.0 provider and browser sign-in of an auth configuration; the command lines of secret managers you configure; the AI provider you set up, only when you ask the assistant (secret values masked, see AI assistant); and hosts a plugin is permitted to reach, which you see before installing it.

What is stored, and where

DataDesktop appWeb app
Collections and environmentsYour foldersYour folders, through the browser's file access
Secret values, OAuth 2.0 tokensOperating system keychainEncrypted in the browser's storage
History: request name, method, masked URL, status, time; no bodies and no header valuesData folderBrowser storage
Cookies set by responses, per collection and environmentData folderBrowser storage
Installed plugins and their storageData folderBrowser storage
AI assistant settings (provider, model, address); its API keyData folder; key in the keychainBrowser storage; key encrypted

rt keeps no history. It shares the keychain entries and the plugin folder with the desktop app, and keeps cookies only in a file you name with --cookie-jar.

The companion rt agent listens on your own machine only (127.0.0.1), logs the method and host of each request it sends, never paths, headers or bodies, and keeps its pairing tokens in memory.

This website

This website is a set of static pages. It sets no cookies, runs no scripts, uses no analytics and loads no fonts, images or scripts from other servers. The hosting provider (GitHub Pages) keeps its own technical server logs; see GitHub's privacy statement for what those contain.
