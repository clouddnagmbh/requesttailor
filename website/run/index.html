Run in RequestTailor

You followed a Run in RequestTailor badge. The repository you came from keeps its API requests as plain files, so you open them straight from a copy of the repository: no import, no account, no upload.

The address of the repository is in your browser's address bar after ?repo=. This page runs no scripts, so it cannot fill it in for you; the steps below say <repository> where it goes. A folder inside the repository may follow after &path=.

On the desktop

  1. Get the app from the download page (macOS).
  2. Clone the repository: git clone <repository>
  3. In RequestTailor, choose Open folder and select the folder that contains opencollection.yml (the repository itself, or the folder given after &path=).
  4. Pick an environment. Secret values (tokens, passwords) are not in the repository; the app asks for them once and keeps them in your keychain.

Changes are ordinary file changes: commit them with the built-in Git view or any Git tool.

In a pipeline or on the command line

With rt from the download page:

git clone <repository> api && cd api
rt run . --env <environment> --reporter junit=junit.xml

rt run sends every request of the collection in order and fails the build when a test or assertion fails. Without a server to call, rt mock . answers with the examples saved in the collection. See Command line: rt.

In the web app

The web app runs from the RequestTailor repository on your own machine; there is no hosted version yet.

git clone https://github.com/clouddnagmbh/requesttailor
cd requesttailor
npm ci --ignore-scripts
node scripts/build-wasm.mjs
npm run dev -w apps/web

Then open the address it prints in Chrome or Edge, choose Open folder and select your clone of <repository>. The browser asks once for access to that folder.

Add the badge to your README

Put the collection in your repository (a folder with opencollection.yml), then add one of these snippets. Replace OWNER/REPO with your repository and, if the collection is not at the root, set path to its folder.
