# Script APIs of the shims in crates/rt-script/js (wave 7): one per line,
#   <api> <supported|partial|unsupported> <note>
# An entry covers its member paths too (`res.body` covers `res.body.items`); the longest
# entry wins. `expect().<word>` is a chai assertion word, `name()` a called global,
# `tests[]` an indexed one, `require('x')` a module. `insomnia.*` falls back to `pm.*`.
#
# Read by the importers (loss report: every unsupported or partial API a kept script uses),
# by scripts/shim-frequency.mjs and by the shim tests, which check that every supported and
# partial API exists. crates/rt-script/SHIM-COVERAGE.md is the readable table.
